# Jas Khetani Portfolio

Vercel-ready portfolio for Jas Khetani: AI systems, automation, quantum/data projects, and selected case studies.

## Stack

- Vite
- React
- Static build for Vercel
- Geist-inspired Vercel visual system

## Local development

```bash
npm install
npm run dev
```

## Build verification

```bash
npm run build
```

## Deployment

Connect this repository to Vercel and use the default Vite settings:

- Build command: `npm run build`
- Output directory: `dist`

## Content strategy

The site curates, rather than mirrors, GitHub:

1. AI Engineering Lab
2. Quantum Computing Projects
3. Sanitized product/case-study work
4. Research communication
5. Writing and now-building notes
